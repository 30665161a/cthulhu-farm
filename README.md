# 🌾 Cthulhu Farm (克苏鲁的农场)

A Stardew Valley-inspired indie game with a Lovecraftian twist. 
(一款融合了星露谷物语玩法与克苏鲁神话元素的独立游戏)

## 🎮 Core Mechanics (核心机制)
- **Dual Economy System (双轨制经济)**: 
  - Daytime: Sell normal crops for Gold.
  - Nighttime: Sacrifice mutated crops for Bone Coins.
- **Day/Night FSM (昼夜状态机)**: Seamless transition between Normal and Eldritch phases.
- **Sanity (SAN) System**: Planting too many eldritch crops drains your SAN, triggering hallucinations and NPC mutations.

## 🛠 Tech Stack (技术栈)
- **Language**: TypeScript / C# (Mockup)
- **Architecture**: Event-Driven, Data-Oriented (JSON Schema).
- **AI Assisted**: Powered by Devin Bot for boilerplate generation, grid logic, and unit testing.
